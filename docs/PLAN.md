## 2. Inflections subtab

**What it shows**

- [x] **Nouns, declensions 1–6.** For each declension: what it looks like
      (ending of the lemma, gender), and the full 7 cases × singular/plural
      table for one or two example nouns — the same words the app already
      teaches (*draugs, brālis, māja, upe, sirds, egle …*).
      Generated by `inflect()` from `content/grammar/` and the lexemes, so
      nothing is typed in by hand (CLAUDE.md rule 5). Only `verified` forms
      are shown; a gap shows as "—", never a guess (ADR-008).
- [x] **Consonant alternation** (brālis → brāļa, egle → egļu) explained
      next to the declensions it applies to, with the rule list from
      `content/grammar/alternations.json`.
- [x] **Pronouns** — the irregular paradigms the app already has
      (es, mēs, viņš, viņa, tas); grows with §5.
- [x] **Which case after which preposition** — a short table built from
      the approved sentences (uz + acc., no / pie / bez / zem + gen.,
      ar + ins., …), each with one example sentence.
- [x] **Not yet:** verbs (conjugations 1–3, tenses, the debitive) and
      adjectives (definite/indefinite). `inflect()` can't produce them yet,
      and the engine work for verbs is open in `content/_needed.json`.
      The page says so instead of hand-written tables. Adding verb
      inflection to the engine is its own future item.

**Check a word on Tēzaurs**

- [x] A text box under the tables: type any word, press **Check** → opens
      `https://tezaurs.lv/<word>` in a new browser tab, where Tēzaurs shows
      the word's entry with its full inflection table.
- [x] Opens with `target="_blank" rel="noopener"`; the word is
      URL-encoded so diacritics survive (`māja` → `m%C4%81ja`).
- [x] Offline (installed app, no network): the button says Tēzaurs needs a
      connection rather than opening a blank tab.

*Feasible:* yes — it's only a link. The app never reads Tēzaurs' data
(no scraping, no API, no runtime dependency — ADR-002), so their
licence and availability don't affect the app.
*To verify when building:* that `tezaurs.lv/<word>` resolves an inflected
form (e.g. *mājā*) to its lemma's entry, or only lemmas. If only lemmas,
say so under the box ("type the dictionary form").

*Size:* medium. **Done 2026-11-12** — plus a "seven cases" table (what each
case is for, one example sentence each). Tēzaurs inflected-form lookup still
to be tried on a real device; the hint under the box says to use the
dictionary form.

## 4. Voice note → write what you heard, with a second try

`listen` exists already (audio → type the Latvian). Changes:

- [ ] **First wrong answer:** don't grade yet. Show the transcript (with the
      **Aa** legend), let the learner play the recording again, and ask
      them to write it once more.
- [ ] **Second answer:** graded as usual. Wrong again → the normal "Not
      quite" feedback, and the card comes back at the end of the session
      like any missed card.
- [ ] **Grading for scheduling:** right on the second try counts as *hard*,
      not *good*. The learner had the transcript in front of them, so it
      was copying, not recall. A near miss (diacritics only) on the first try is
      still a near miss, no retry needed.
- [ ] The review log records both attempts, so the dashboard can show how
      often the second try was needed.
- [ ] Applies to `listen` only. The other typed cards keep one try.

*Open question for you:* should the transcript on the retry show the
whole sentence, or hide the words you got right and only show the ones you
missed? Whole sentence is simpler and is the default unless you say
otherwise.

*Size:* medium. Reducer change (a "retry" phase), grading rule, UI, an ADR.

## Before recordings go in at scale

- [ ] **Don't precache audio.** Today the service worker downloads *every*
      file in the build on install and again after every deploy
      (`scripts/build-sw.ts`). Fine for 50 short clips (~1 MB), wasteful
      for hundreds. Change it so audio is cached the first time it's played
      instead, and doesn't expire with each deploy. Do this before the
      recordings pass a few MB.
- [ ] `content:check` already warns about a sentence whose `audio` file
      is missing. Add the reverse: a file in `public/audio/` that no sentence
      points to (a typo in a file name).
