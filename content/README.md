# content

Authored data — lexemes, sentences, and grammar tables — stored as JSON and validated
against the Zod schemas in `src/content/schemas.ts`. Every Latvian sentence, gloss, and
inflected form here is written or reviewed by a human, never generated by a model (see
ADR-004 in `docs/DECISIONS.md`); missing content is tracked as a `TODO` entry in
`content/_needed.json` instead of being invented.
